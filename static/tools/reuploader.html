Animation Re-Uploader

Upload ulang animasi Roblox ke akun kamu sendiri. Paste ID, dapat Asset ID baru + script siap pakai.

Akun tujuan upload

Akun & API key dikelola di Pengaturan. Klik akun untuk memilih yang aktif.

Cara kerja

  1. Tempel link / ID animasi Roblox
  2. Tambah & pilih akun tujuan upload
  3. Klik Upload → animasi di-upload ke akunmu
  4. Dapat Asset ID baru + script siap pakai
Pakai animasi milik sendiri / free / yang kamu punya izinnya. Tanggung jawab ada di kamu sebagai pengguna.

Cara buat API Key

  1. Buka create.roblox.com → Credentials → API Keys
  2. Tambah API System: Assets (Read + Write) dan Legacy Assets (Manage / Use)
  3. Isi IP 0.0.0.0/0 bila perlu, lalu Save & salin key
  4. Untuk grup, pemilik key harus punya izin upload grup
