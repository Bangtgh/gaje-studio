Satu tempat untuk
kebutuhan Roblox kamu

Roblox adalah platform tempat jutaan orang membuat dan memainkan game buatan komunitas. Di balik setiap game ada aset: animasi, suara, dan model 3D. Gaje Studio menyatukan tiga alat bantu untuk mengurus aset-aset itu dengan cepat, langsung dari komputer kamu.

Fungsi setiap tool

Seputar Roblox

Roblox Studio

Aplikasi gratis untuk membuat game: menyusun dunia, menulis script Lua (Luau), dan mengimpor aset seperti model, suara, dan animasi.

Asset ID

Setiap aset yang diunggah mendapat angka unik. Angka itu dipakai di script, misalnya rbxassetid://123456, untuk memanggil animasi atau suara.

Open Cloud API

Jalur resmi Roblox untuk mengunggah aset lewat API key, tanpa harus membuka Studio. Dipakai oleh Animation Re-Uploader dan Audio.

⚙ PENGATURAN

Pengaturan

Akun Roblox

Isi di sini untuk browser ini. Akun aktif dipakai oleh Animation Re-Uploader dan Audio Studio. Jangan simpan API key di perangkat bersama.

Cara buat API key: create.roblox.com → Credentials → API Keys. Scope: Assets (Read + Write) dan Legacy Assets (Manage). Untuk memperbarui key, simpan ulang dengan ID yang sama.

ℹ TENTANG

Tentang Gaje Studio

Gaje Studio adalah gabungan tiga aplikasi web menjadi satu: Animation Re-Uploader, 3D Maker, dan Audio Studio. Situs ini berjalan dengan server Python.

Pengunggahan ke Roblox memakai Open Cloud API dengan API key milikmu. Gunakan hanya aset milik sendiri, gratis, atau yang kamu punya izinnya. Tanggung jawab penggunaan ada pada pengguna.

Teknologi

Flask, yt-dlp, FFmpeg, Roblox Open Cloud, three.js

Cara menjalankan

Secara lokal, jalankan run.bat, lalu buka http://localhost:5000. Di hosting, buka URL Render yang diberikan.
